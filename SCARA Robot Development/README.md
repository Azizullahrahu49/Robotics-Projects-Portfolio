# SCARA Robot Development

## 1. Project Title

**Design and Development of a SCARA Robotic Manipulator**

## 2. Short Description

Developed a **SCARA robotic manipulator** for precise and coordinated robotic motion. The project focused on robotic mechanism design, kinematic analysis, actuator integration, and motion control, providing practical experience in the development of industrial-style robotic systems.

## 3. My Contribution

* Designed and developed the mechanical structure of the SCARA robot.
* Performed robot kinematic analysis for position and motion calculation.
* Integrated motors and actuators for coordinated joint movement.
* Developed the control system for robotic motion and positioning.
* Tested the robot's workspace, movement accuracy, and repeatability.
* Integrated mechanical, electrical, and control components into a functional robotic system.

## 4. Hardware / Components

* SCARA Robot Mechanical Structure
* Stepper Motors
* Servo Motor
* Motor Drivers
* Arduino Mega 
* Robotic Joints and Linkages
* Power Supply
* End-Effector
