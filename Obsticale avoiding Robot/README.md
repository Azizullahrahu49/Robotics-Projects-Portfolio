# Obstacle Avoiding Robot

## 1. Project Title

**Autonomous Obstacle Avoiding Robot Using Ultrasonic Sensing**

## 2. Short Description

Developed an **autonomous mobile robot** capable of detecting and avoiding obstacles in real time using ultrasonic sensing. The system integrates distance measurement, embedded decision-making, and motor control to enable autonomous navigation while minimizing collisions.

## 3. My Contribution

* Designed and developed the mechanical and electrical architecture of the mobile robot.
* Integrated ultrasonic sensors for real-time obstacle detection and distance measurement.
* Developed the embedded control logic for autonomous navigation and obstacle avoidance.
* Implemented motor control for forward, reverse, and directional movements.
* Programmed the robot to make real-time navigation decisions based on sensor measurements.
* Integrated the sensing, control, and actuation subsystems into a functional autonomous robotic platform.
* Conducted testing and troubleshooting to improve obstacle detection and navigation performance.
